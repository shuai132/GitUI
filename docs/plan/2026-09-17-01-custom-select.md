# 统一应用内 Select

## Context

Markdown「源码差异」等选择入口使用系统原生下拉菜单，外观随操作系统变化，也无法完整跟随应用主题。将现有十处 Select 和两处字体 datalist 收口到公共组件，统一深浅色、强调色、密度和键盘行为；分支、目录、字体等长列表支持搜索。

## 关键决策

- 复用应用 CSS 主题变量和现有图标风格，不增加 UI 库；小型工具栏使用紧凑尺寸。
- AppSelect 保留 string/number 的领域类型，选择事件直接传值，不依赖 DOM 字符串转换；自由输入通过显式转换函数启用，避免破坏枚举和数值选择的约束。
- 焦点留在触发控件，通过 combobox/listbox 语义表达候选项。打开时 Escape 先关闭候选，Tab 保留页面及 Modal 的焦点顺序；输入框保留原生文本编辑快捷键。
- 候选弹层脱离内容滚动容器，按视口空间决定向上或向下展开；Modal 内挂载到所属 dialog，保留无障碍归属，其他入口挂载到 body。只在打开期间监听定位事件，长列表仅挂载可见候选，不限制可选择的完整数据集。
- 外部滚动时重新定位，触发控件移出可见区域才关闭；避免浏览器在聚焦、大字号布局变化后自动滚动时意外关闭刚打开的候选。
- 仅更换选择控件，不改变 Git 操作、冻结仓库上下文、分支校验或设置保存失败回滚逻辑。
