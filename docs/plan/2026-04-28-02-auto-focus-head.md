# 自动定位当前 HEAD

## Context

历史图默认展示所有本地、远程、标签和 HEAD 可达提交。当前分支很久没有新提交、其他分支近期提交很多时，初始分页会被其他分支占满，用户刚打开仓库看不到当前分支位置。

目标是在保持默认全量图的前提下，打开或切换仓库后自动把当前 HEAD 滚入视野；不切换到 Solo 当前分支，也不自动打开提交详情。

## 关键决策

- 默认仍保持 `all + showRemoteBranches=true`，不改变日志来源语义。
- 自动定位只在打开/切换仓库的初始加载后触发；普通刷新不强行改变用户滚动位置。
- 自动 HEAD 定位只滚动，不选中提交、不打开详情；当前 HEAD 行用轻量底色和左侧细线提示位置。
- 手动点击侧边栏分支、远程分支、tag、stash 仍会选中目标提交并打开详情，但目标不在当前页时先补页。

## 验证方式

1. 前端单元测试覆盖目标已加载时不补页、目标在后续页时补页找到、目标不存在时停止。
2. 手工验证当前分支 HEAD 很旧的仓库，打开后默认全量图自动滚到 HEAD，详情保持关闭。
3. 运行 `npx vue-tsc --noEmit`、`npm run test`、`cd src-tauri && cargo check`、`cd src-tauri && cargo test`。
