# 同名仓库自动消歧

## Context

GitUI 的“所有仓库”只显示本地目录名，完整路径仅在悬停提示和右键复制路径中可见。当 fork、多份 checkout、同名 worktree 或不同组织的仓库使用相同目录名时，用户在点击或键盘切换前无法确认目标，选错后还会触发完整的仓库激活刷新。

[GitHub Desktop 官方文档](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop#creating-an-alias-for-a-local-repository)专门提供本地仓库别名来解决同名仓库区分问题；GitUI 的多窗口托盘也已经在同名仓库后附加路径。此次把消歧能力补到使用频率更高的侧栏名册，并采用无需配置的自动策略。

## 关键决策

- 只对名称完全相同的仓库显示消歧信息；普通列表保持现有单行密度。
- 从父目录末尾向前寻找最短唯一片段，比直接显示绝对路径更易扫读，也避免侧栏被共同路径前缀占满。
- 消歧只影响展示，不新增别名配置、不修改 `RepoMeta`、持久化数据或 IPC 契约。
- 完整路径继续作为行标题；最短标签不足时退回规范化父路径，确保不会输出相同标签。

## 验证方式

1. 打开两个末级目录同名、父目录不同的仓库，确认两行名称后显示最短可区分父路径。
2. 打开父目录末级也相同的两个同名仓库，确认算法自动多显示一级。
3. 确认非同名仓库、搜索、键盘快速切换、拖动排序和 Submodule 缩进不回归。
4. 运行 `npx vue-tsc --noEmit`、`npm run test`、`cd src-tauri && cargo check`、`cd src-tauri && cargo test`。
