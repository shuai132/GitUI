# 历史列表列自定义

## Context

历史列表目前列顺序固定，且「变更」列始终显示。用户希望列头可拖动调整顺序，并能在设置里隐藏「变更」列。目标是在不改变后端 IPC、不拖慢历史加载和虚拟滚动的前提下，为历史列表增加轻量的列偏好。

## 关键决策

- 列顺序是全局偏好，不按仓库分别保存。
- 「变更」列默认显示；隐藏只影响列表渲染和懒加载触发，不清空已有缓存。
- 参与排序的只有数据列：描述、变更、提交、作者、日期；提交图列和 dock 拖拽手柄固定。
- 列宽继续沿用已有 `historyPaneSizes`，排序不改变列宽。
