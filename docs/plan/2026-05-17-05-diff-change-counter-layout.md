# Diff 变更跳转控件紧凑布局

## Context

Diff 工具栏的上一 / 下一变更按钮当前横向占用两个按钮宽度，且没有显示当前变更块序号。用户希望按钮改为上下排列以减少横向占位，并在按钮附近显示 `m/n`。同时，从 inline 切换到 side-by-side 或反向切换时，当前已经跳转并高亮的变更块需要继续保持高亮。

本次改动只涉及 Diff 前端组件内部状态和工具栏展示，不新增 IPC、Rust 后端接口或数据结构。

## 关键决策

- 当前变更索引由 `DiffView` 持有，布局组件通过事件请求更新，避免切换布局时销毁组件导致高亮状态丢失。
- 变更数量由当前渲染组件根据实际行模型上报；如果当前索引超出数量范围，父级清空为 `-1`。
- 工具栏显示 `0/n` 表示当前文件有变更但尚未跳转；无变更时显示 `0/0`。
- 只在切换文件 / diff 内容变化时清空当前索引；切换 inline / side-by-side 时不清空。

## 验证方式

- 组件测试：键盘或按钮跳转后工具栏显示 `m/n`。
- 组件测试：从 inline 切到 side-by-side 后当前高亮仍存在。
- 组件测试：无变更时方向键继续冒泡给外层导航。
- 运行 `npx vue-tsc --noEmit` 和相关 diff 组件测试；必要时跑 `npm run test`。
