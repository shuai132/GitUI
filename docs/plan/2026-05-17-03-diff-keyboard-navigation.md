# Diff 键盘导航与当前块高亮

## Context

Diff 查看器已经支持通过工具栏按钮跳转上一 / 下一变更块，但在正文阅读时键盘上下键仍可能被外层历史列表接管。目标是在用户点击普通文本 Diff 正文后，让无修饰键的 `↑/↓` 直接跳转上一 / 下一变更块，并在跳转后给当前块一个不覆盖红 / 绿语义的当前位置指示。

本次改动只涉及前端 Diff 组件内部交互，不新增 IPC、Rust 后端接口、store 字段或数据结构。

## 关键决策

- 只在 Diff 正文获得焦点后接管无修饰键 `ArrowUp` / `ArrowDown`；带 `Alt` / `Meta` / `Ctrl` / `Shift` 的组合键继续走现有全局逻辑。
- 输入框、按钮、选择框、链接和 `contenteditable` 内的键盘事件不接管，避免破坏控件默认交互。
- 当前块指示使用边框、inset 阴影和左侧 accent 线，不修改行高，不增加行内 padding，不用强底色覆盖新增 / 删除背景。
- 当前范围随 diff 行数据、布局或文件身份变化清空，避免切换后保留旧文件位置。

## 验证方式

- 组件测试：点击 Diff 正文后，`ArrowDown` 调用下一变更、`ArrowUp` 调用上一变更，并阻止事件冒泡。
- 组件测试：跳转后当前变更行带 `change-current`，切换 diff 后高亮清空。
- 手动关注：inline、side-by-side、按 hunk 分组和完整文件视图下当前位置指示不遮挡 diff 红 / 绿语义。
- 提交前运行 `npx vue-tsc --noEmit`、`npm run test`、`cd src-tauri && cargo check`、`cd src-tauri && cargo test`。
