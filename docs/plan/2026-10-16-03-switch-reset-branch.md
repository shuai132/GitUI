## 关键决策

- 保留当前分支的既有 Reset 子菜单，新增独立入口，避免改变已有操作习惯。
- 表单冻结打开时的仓库、HEAD、目标提交和本地分支候选；提交前检查仓库上下文，后端复核 HEAD 和所选分支 OID。
- 新增单一组合命令，先验证模式、提交、本地分支、工作区与仓库状态，再执行 safe checkout 和 Reset，避免前端两个独立命令之间误用 active repo。
- 组合操作要求没有 staged / unstaged / untracked 改动，也不能处于 Merge / Rebase 等进行中的 Git 操作；提示先提交或 Stash。沿用原 Reset 入口处理已有改动，不额外引入 Stash 生命周期。
- 支持 Soft / Mixed / Hard，默认 Mixed；说明保留的是所选分支切换后的工作区 / Index，Hard 使用危险按钮与明确说明。
- 禁止重置被其他 Worktree 检出的分支。失败保留表单并刷新实际状态，避免操作部分完成时界面仍展示旧 HEAD。
- 仅在打开表单与执行操作时处理分支及工作区，不改动日志、分页、提交图等热路径。

## 验证方式

- 在含两个本地分支的临时仓库，右键旧提交并选择另一分支，分别验证三种模式下 HEAD、原分支指针、Index 与工作区结果。
- 覆盖 detached HEAD、当前分支、远程分支排除、候选为空、分支已移动 / 删除、HEAD 已变化、脏工作区、进行中的 Git 操作、Worktree 占用、错误重试与防重复提交。
- 运行 `npx vue-tsc --noEmit`、`npm run test`、`cargo check`、`cargo test`，并执行 `cargo fmt`。
