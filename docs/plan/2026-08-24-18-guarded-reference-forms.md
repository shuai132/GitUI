# Guarded Reference Forms

## Context

GitUI 允许在多个仓库间快速切换，但新建分支、创建 Tag、检出远程分支与分支页内联新建表单目前都在提交时读取当前 active repo。表单打开后若切换仓库，旧输入、旧提交或旧远程分支可能被应用到另一个仓库。目标是把这些表单绑定到打开时的仓库和引用快照，在上下文变化时保留输入并拒绝执行，切回原仓库后仍可继续。

## 关键决策

- 表单检测到 active repo 变化时不自动关闭、不清空输入，也不把旧操作迁移到新仓库；显示内联错误并允许用户切回原仓库继续。
- 历史页创建分支时冻结打开时的提交；从 HEAD 创建时也保存当时的 HEAD OID，避免等待期间 HEAD 变化导致分支落点漂移。
- store 为这些操作接收显式 repoId，并且只在目标仓库仍 active 时刷新可见状态；不让延迟完成的请求污染另一个仓库的列表。
- 不修改 IPC 契约；后端命令已经接收显式 repoId 与引用目标，本项只收紧前端调用边界。

## 验证方式

- 打开各表单并填写内容，切换仓库后提交，确认请求未发出、输入保留且出现上下文提示；切回原仓库后可继续提交。
- 创建分支时确认传入打开表单时的提交 OID；创建后切换也明确作用于同一 repoId。
- 运行目标 Vitest、`npx vue-tsc --noEmit`、`npm run test`、`cargo fmt`、`cargo check`、`cargo test`。
