# 仓库行键盘激活与拖拽边界

## Context

“所有仓库”是切换仓库的主入口，但可用仓库行目前由外层 `div` 处理 click，并与 pointer 拖拽排序、右键菜单和行尾移除按钮混在同一交互区域。直接把外层替换为按钮会产生按钮嵌套，也可能破坏拖拽热路径。

预期结果：保留外层行作为拖拽 / 右键容器，在其中拆出原生仓库激活按钮和独立移除按钮；键盘可切换仓库，当前仓库状态可读，拖拽排序语义与性能不变。

## 关键决策

- 不改变 drag threshold、目标索引计算或 store 调用，只调整 DOM 事件入口。
- 激活按钮的 pointerdown 继续冒泡到外层，保证从名称 / 图标开始拖动仍可排序；内部图标文本不单独接收 pointer。
- 行尾移除按钮保持独立，不嵌入激活按钮，并在 `focus-within` 时显现。

## 验证方式

1. Tab 聚焦仓库激活按钮，用 Enter / Space 切换；当前项声明 `aria-current`。
2. 从仓库名称区域拖动，确认原有阈值和重排调用仍工作。
3. Tab 聚焦移除按钮，确认按钮显现且只执行移除。
4. 右键仓库行，确认菜单目标不变；激活 / 移除 / 重排失败仍显示非阻塞反馈。
5. 运行 `npx vue-tsc --noEmit`、`npm run test`、`cd src-tauri && cargo check`、`cd src-tauri && cargo test`。
